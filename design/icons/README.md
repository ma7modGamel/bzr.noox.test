# أيقونات الواجهة

كل ملف SVG في هذا المجلد يستخدم `viewBox="0 0 24 24"` ومسارًا واحدًا (`<path d="…"/>`).

- **خطية (الافتراضي):** `fill="none"` وخط مستدير. سُمك الخط ولونه الافتراضي من `tokens.json → icon`.
- **مملوءة:** `fill="currentColor" stroke="none"` (مثل `star-filled` و`warning-filled`)، و`fill-rule="evenodd"` لو فيها فراغات داخلية.

يولّد `tools/gen-design` من كل ملف Android Vector Drawable وiOS Asset Catalog، ومعاهم `BzrIconKey` في Swift. المولّد بيطبّع بيانات المسار (يفك أعلام القوس المضغوطة زي `a4 4 0 100-8`، اللي محلل Android بيقراها غلط)، فالمنصتين بيستلموا نفس المسار بالظبط. لا تُنسخ الأيقونات يدويًا إلى التطبيقات.

الاتجاه: التطبيقان RTL فقط، والأسهم مرسومة بالاتجاه اللي ظاهر في اللقطات (`arrow-back` و`chevron` بيشيروا لليسار)، فمفيش قلب تلقائي.
