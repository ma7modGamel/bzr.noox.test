# 36 — ما بعد النسخة الأولى

مفصول تمامًا عن نطاق التجربة. لا يُبنى أي منها الآن، لكن التصميم لا يمنعها — باستثناء أول بندين: هما **مبنيان بالكامل في النسخة الأولى ومعطّلان بمفتاح** (39).

| البند | ما يلزمه لاحقًا |
|---|---|
| **تفعيل وضع السوق** (CFG-090) — مبني بالكامل | حسم OD-01/OD-02 ثم تبديل المفتاح؛ لا كود ولا ترحيل (39 §التبديل) |
| **تفعيل رسوم المعاينة** (CFG-091) — مبني بالكامل | تبديل المفتاح بعد CFG-090 (BR-009) |
| وضع تشغيل لكل مدينة أو فئة | نقل CFG-090/091 من إعداد عام إلى إعداد بنطاق (نفس جدول الإعدادات بنطاق) |
| موظفون ومستقلون جنبًا إلى جنب على نفس الطلب | قرار مالك جديد: هل يتنافس الموظف على العروض؟ وقواعد أولوية في التعيين |
| طلبات الطوارئ (DEC-012) | علامة على الطلب، نافذة أقصر، توزيع على "متاح الآن" فقط |
| البحث و"مميزون" (DEC-034) | صفحات عرض؛ الحجز المباشر مسار جديد إن طُلب |
| شركات وفرق فنيين (DEC-001) | كيان `Organization` يملك ملفات فنيين + صلاحيات داخلية |
| إنستاباي لدفع العملاء (OD-06) | مجمّع دفع؛ نفس جدول `payments` |
| حفظ البطاقات (ASM-05) | Tokenization من فوري |
| تحويلات تلقائية للفنيين | واجهة تحويل من مزود دفع + إعادة النظر في التسويات |
| SMS/واتساب لرمز الدخول أو الأحداث الحرجة | قناة إضافية في Notifications |
| مدن جديدة | إعداد فقط (20) |
| حدود المناطق كمضلعات | تحديد المنطقة آليًا من الموقع |
| عمولة أو إعدادات لكل مدينة/فئة | جدول إعدادات بنطاق |
| رسوم إلغاء بعد الوصول | قرار مالك جديد + قاعدة في 13 |
| WebSocket للمحادثة والتتبع | Laravel Reverb |
| تكرار طلب سابق | زر ينسخ بيانات الطلب |
| تقارير تحليلية | لوحة قراءة فقط |
