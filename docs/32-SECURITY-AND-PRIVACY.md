# 32 — الأمان والخصوصية

متطلبات عملية فقط، بلا بيروقراطية امتثال.

## المصادقة
- كلمات المرور: bcrypt/argon2، 8 أحرف على الأقل.
- Sanctum tokens لكل جهاز، تُلغى عند الخروج وتغيير كلمة المرور وحظر الحساب.
- البريد يجب توثيقه قبل النشر أو التقديم كفني (BR-001).
- الإدارة: جلسات منفصلة (guard `admin`)، كلمات مرور قوية، **مصادقة ثنائية TOTP إلزامية** (Filament يدعمها)، خروج تلقائي بعد 30 دقيقة خمول.

## الصلاحيات والملكية
- Policy لكل مورد؛ المورد غير المملوك يعيد `404` (23).
- الفني يرى من الطلب ما في BR-024 فقط قبل التأكيد؛ الاستجابات تُبنى بـ Resources مختلفة حسب الطرف والحالة (لا تُرسل حقول ثم تُخفى في التطبيق).
- الإجراءات الإدارية المالية للمدير العام فقط (23).

## البيانات الحساسة
| البيان | الحماية |
|---|---|
| مستندات الهوية | تخزين خاص، روابط موقّعة 15 دقيقة، للإدارة فقط، لا تُرسل للتطبيقات أبدًا |
| بيانات استلام المستحقات | تشفير على مستوى الحقل (Laravel encrypted cast)، تظهر مقنّعة في اللوحة إلا للمدير العام |
| نص الرسائل الأصلي قبل الحجب | مشفر، يُفتح للإدارة عند نزاع أو بلاغ فقط |
| العنوان التفصيلي | للعميل، والفني المختار بعد التأكيد، والإدارة |
| الهاتف | BR-101/102 |
| الموقع | BR-110..112، رابط المشاركة بلا موقع (DEC-037) |
| الدفع | لا تُخزن بيانات بطاقات إطلاقًا؛ فقط مراجع فوري |

## الوسائط
- فحص النوع الفعلي (MIME)، الحجم، المدة. إزالة بيانات EXIF (الموقع) من الصور.
- أسماء ملفات عشوائية، لا مسارات يمكن تخمينها.
- وسائط الطلب يراها: العميل، الفنيون المؤهلون أثناء OPEN، الفني المختار، الإدارة.

## Webhook فوري
التحقق من التوقيع، مطابقة المبلغ والمرجع، رفض التكرار، تسجيل الحمولة الأساسية فقط.

## الحماية العامة
- HTTPS فقط، HSTS.
- حدود المعدل (31).
- حماية CSRF للوحة، وسياسة CORS مغلقة للـ API.
- phpMyAdmin غير مكشوف للعامة؛ قاعدة البيانات لا تستمع إلا على الشبكة الداخلية.
- تسجيل محاولات الدخول الفاشلة للإدارة.
- تحديثات أمنية شهرية للاعتماديات.

## الاحتفاظ بالبيانات
| البيانات | المدة |
|---|---|
| نقاط المسار | حتى إغلاق الطلب |
| نقطة الوصول | 90 يومًا |
| الوسائط المؤقتة غير المنشورة | 24 ساعة |
| روابط المشاركة | حتى نهاية الطلب |
| الطلبات والأحداث والدفعات | دائم (مجهولة الهوية عند حذف الحساب) |
| مستندات هوية الفني المرفوض | 90 يومًا بعد الرفض النهائي ثم حذف |

سياسة الخصوصية النصية تحتاج مراجعة قانونية (OD-04).
