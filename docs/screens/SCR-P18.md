# SCR-P18 — المستحقات

- النمط: C — ملخص وقائمة.
- المرجع البصري: SCR-C21 لملخص المبالغ وSCR-C25 للقائمة.
- الطرف والوضع: الفني — الموظفين والسوق.
- الدخول من: عنصر «المستحقات» في تنقل الفني · الخروج إلى: تفاصيل الطلب أو SCR-P08.
- القواعد: BR-060..065، DEC-057.
- الـ API: `GET /provider/earnings?page={page}&type={code}&date_from={Y-m-d}&date_to={Y-m-d}`، و`GET /provider/earnings/export` بنفس الفلتر.
- التخطيط (من أعلى لأسفل):
  1. `AppTopBar` بعنوان `provider.earnings.title`.
  2. ثلاث `StatRow`: الرصيد المحسوب، المتاح للتسوية، والمعلّق.
  3. في وضع الموظفين `InfoBanner` يشرح المطلوب توريده وقيمة الخامات التي تردها المنصة.
  4. قائمة حركات مرتبة زمنيًا: طلب مغلق، تحويل للفني، أو توريد من الفني؛ النص والنوع من الخادم.
- المتغيرات: موظف / مستقل / قائمة فارغة / تحميل صفحة تالية.
- الحالات: تحميل / خطأ / فارغ / محتوى / تحميل المزيد.
- الأخطاء: فشل الصفحة التالية يبقي القائمة الحالية ويتيح إعادة المحاولة.
- fixtures: `design/fixtures/SCR-P18/cases.json`.
- أسئلة مفتوحة: OD-12 يؤثر في تقرير الموظفين بالدفعة 8 فقط، ولا يغيّر هذه الشاشة.

## قرار الشات 16 — 14 أكتوبر 2026

أُضيفت خيارات نوع الحركة من الخادم والفترة بتاريخين اختياريين بالتوقيت العالمي المنسّق، مع تطبيق الفلتر ومسحه وتصدير CSV وتحميل المزيد. الملخص يخص إجمالي الحساب؛ الحركات والتصدير يخصان الفلتر. التصدير يشمل كل الصفحات. تعديل الفلتر يمنع التصدير وتحميل المزيد حتى تطبيقه. فشل التحديث يبقي القائمة الحالية؛ القائمة الفارغة لا تخفي أدوات إعادة الضبط والتصدير. Android يشارك ملفًا خاصًا عبر النظام، وiOS يفتح حوار حفظ الملف.
