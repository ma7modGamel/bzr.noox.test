# SCR-P18 — المستحقات

- النمط: C — ملخص وقائمة.
- المرجع البصري: SCR-C21 لملخص المبالغ وSCR-C25 للقائمة.
- الطرف والوضع: الفني — الموظفين والسوق.
- الدخول من: عنصر «المستحقات» في تنقل الفني · الخروج إلى: تفاصيل الطلب أو SCR-P08.
- القواعد: BR-060..065، DEC-057.
- الـ API: `GET /provider/earnings?page={page}`.
- التخطيط (من أعلى لأسفل):
  1. `AppTopBar` بعنوان `provider.earnings.title`.
  2. ثلاث `StatRow`: الرصيد المحسوب، المتاح للتسوية، والمعلّق.
  3. في وضع الموظفين `InfoBanner` يشرح المطلوب توريده وقيمة الخامات التي تردها المنصة.
  4. قائمة حركات مرتبة زمنيًا: طلب مغلق، تحويل للفني، أو توريد من الفني؛ النص والنوع من الخادم.
- المتغيرات: موظف / مستقل / قائمة فارغة / تحميل صفحة تالية.
- الحالات: تحميل / خطأ / فارغ / محتوى / تحميل المزيد.
- الأخطاء: فشل الصفحة التالية يبقي القائمة الحالية ويتيح إعادة المحاولة.
- fixtures: `design/fixtures/SCR-P18/cases.json`.
