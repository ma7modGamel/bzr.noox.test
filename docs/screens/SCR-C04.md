# SCR-C04 — طلب جديد: تفاصيل الزيارة

- النمط: A — نموذج، الخطوة 2 من 3.
- المرجع البصري: `design/reference/C04-request-step2-visit.jpeg` بعد تعديلات 27 §أ و§أ-2.
- الطرف والوضع: العميل، في وضعي الموظفين والسوق.
- الدخول من: SCR-C03 · الخروج إلى: SCR-C05، SCR-C14 لاختيار العنوان، SCR-C16 لاختيار الفترة.
- القواعد: BR-008، BR-010، BR-015، BR-016، BR-017، DEC-035، DEC-040، DEC-041.
- الـ API: `GET /config`، `GET /addresses`، `GET /slots?city_id={id}&date={date}` عبر SCR-C16.
- التخطيط (من أعلى لأسفل):
  1. `AppTopBar` ثم `StepIndicator` 2/3.
  2. `SummaryCard` للعنوان المختار وزر تغيير إلى SCR-C14.
  3. `SelectableChip`: الآن، اليوم، موعد آخر. اليوم وموعد آخر يفتحان SCR-C16، وتظهر الفترة المختارة تحتهما.
  4. الآن معطّل خارج `service_hours` ويظهر `request.timing.now.unavailable`.
  5. في السوق فقط: `RadioCard` لطريقة التسعير، ثم `AmountField` اختياري و`CheckRow` لاستقبال عروض بلا ميزانية.
  6. في وضع الموظفين: إخفاء التسعير والميزانية وعرض `InfoBanner` بنص `request.staff.inspection.free`.
  7. `SelectableChip` لمسؤولية الخامات: عندي الخامات / الفني يوفرها / غير محدد.
  8. `PrimaryButton` بالمفتاح `request.step2.action`.
- المتغيرات: موظفين/سوق؛ الآن داخل/خارج الساعات؛ مجدول بفترة/دون فترة؛ تنفيذ/معاينة؛ مسؤوليات الخامات الثلاث.
- الحالات: تحميل / خطأ / عدم اتصال / عنوان مفقود / فترة مفقودة / جاهز.
- الإجراءات: أزرار الاختيار والمتابعة تخص مسودة محلية؛ لا يوجد طلب منشور بعد.
- الأخطاء: BR-010 أو BR-017 ← إبقاء الشاشة وشرح الحقل؛ خطأ النقل ← `error.body`.
- fixtures: `design/fixtures/SCR-C04/cases.json`.
