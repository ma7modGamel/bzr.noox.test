# SCR-W01 — متابعة زيارة عبر رابط عام

## الغرض والنطاق

صفحة ويب عامة للقراءة فقط تسمح لمن يملك رابط المشاركة بمتابعة حالة زيارة فني مسند، من دون تسجيل دخول. تتبع النمط D المبسّط، واتجاهها RTL، ومصممة بعرض موبايل. مصدر القيم البصرية هو `design/tokens.json` عبر CSS مولّد فقط، والخط Cairo.

## المسار ودورة الحياة

- المسار: `GET /v/{token}`.
- الرمز عشوائي 256-bit، ولا يظهر في أي سجل يكتبه التطبيق.
- الرابط صالح ما دام غير ملغى، وغير منتهٍ زمنيًا إن كان له تاريخ انتهاء، والطلب ليس في حالة نهائية.
- الرمز المفقود أو غير الصالح أو الملغى أو المنتهي، وكذلك الطلب `CANCELLED` أو `EXPIRED` أو `CLOSED`، يعيد HTTP `410` وصفحة: «انتهت صلاحية هذا الرابط».
- حد المعدل: 60 طلبًا في الدقيقة لكل IP.
- الصفحة تعيد تحميل نفسها تلقائيًا كل 30 ثانية.

## الخصوصية والتخزين المؤقت

- الاستجابة تحمل `Cache-Control: no-store, private` و`X-Robots-Tag: noindex, nofollow, noarchive`.
- تحتوي الصفحة `<meta name="robots" content="noindex,nofollow,noarchive">` وسياسة إحالة `no-referrer`.
- لا يصل إلى قالب العرض كائن الطلب أو العميل؛ يمرر المتحكم View Model محدودًا بالحقول المذكورة أدناه.
- ممنوع عرض أو تضمين: العنوان التفصيلي، الخريطة، الإحداثيات أو الموقع الحي، الهاتف، السعر أو أي مبالغ، واسم العميل أو أي بيانات تخصه.

## ترتيب المحتوى

من أعلى إلى أسفل:

1. اسم التطبيق.
2. `ProviderHeader`:
   - صورة الفني، أو بديل بصري محايد عند عدم وجودها.
   - الاسم الأول فقط.
   - درع التوثيق.
   - النص: «فني [الفئة] موثّق».
3. كارت الحالة:
   - النص المحسوب من `display_status`.
   - `EtaCard` يظهر فقط في `ON_THE_WAY`.
   - يعرض وقت الوصول بالدقائق، وعند `eta_approximate=true` تظهر كلمة «تقريبي».
4. `StatusStepper` بالقيم `done | active | pending | on_hold`.
   - في `DISPUTED` تبقى آخر مرحلة قبل النزاع هي المحددة، وتأخذ `on_hold` بلون `star`، ويظهر `WarningBox` بنص «قيد المراجعة».
   - `OPEN` و`CANCELLED` و`EXPIRED` لا تعرض الشريط (`stepper = null`) وتعرض كارت حالة بالسبب مكانه. الحالات النهائية لا تصل لهذه الصفحة بسبب استجابة 410.
5. صف رقم الطلب.
6. صف اسم المنطقة.

## عقد بيانات العرض

```text
app_name: string
provider: {
  first_name: string,
  avatar_url: string|null,
  category_name: string,
  verified: true
}
display_status: string
status: OrderStatus
eta: { minutes: int|null, approximate: bool }|null
stepper: [{ key: string, state: done|active|pending|on_hold }]|null
warning: string|null
order_number: int
area_name: string
```

لا تُضاف حقول أخرى إلى هذا العقد من دون تحديث هذه المواصفة ومراجعة الخصوصية.

## الوصول والحالات

- عناصر الشريط لها نص مرئي، وليست معتمدة على اللون وحده.
- الصورة البديلة تحمل أول حرف من الاسم، وصورة الفني — إن وجدت — لها نص بديل باسم الفني الأول.
- التباين، المسافات، الحواف، الأحجام، والألوان تأتي من رموز التصميم.
- الصفحة لا تحتوي أزرار اتصال أو محادثة أو تنقل؛ هي متابعة للقراءة فقط.

## معايير القبول

- الصفحة الصالحة ترجع 200 وتعرض العناصر بالترتيب المحدد.
- `EtaCard` لا يظهر إلا في `ON_THE_WAY`، وتظهر «تقريبي» فقط عند تفعيل العلم.
- النزاع يعرض `on_hold` و«قيد المراجعة» مع إبقاء المرحلة السابقة.
- أي رابط غير صالح يعيد 410 بالنص المحدد.
- اختبارات الاستجابة تؤكد عدم وجود قيم العنوان، الإحداثيات، الهاتف، السعر، أو اسم العميل في HTML.
- CSS والأصول اللازمة قابلة لإعادة التوليد من `tools/gen-design` بلا فروق.
