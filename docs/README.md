# وثائق المنتج — منصة خدمات صيانة المنازل

هذا المجلد هو **المصدر الوحيد المعتمد** لسلوك المنتج. أي تعارض بين وثيقتين يُحل بالرجوع إلى الوثيقة "المرجعية" للموضوع (انظر الجدول).

> **اقرأ 39-OPERATING-MODES أولًا.** الوثائق من 01 إلى 38 تصف النموذج الكامل (**وضع السوق**). المرحلة الأولى تعمل في **وضع الموظفين**: بلا عروض سعر وبمعاينة مجانية، بمفتاحين في الإعدادات (CFG-090، CFG-091) يُفعَّلان من الداشبورد لاحقًا — DEC-039، DEC-040.

| الموضوع | الوثيقة المرجعية |
|---|---|
| قواعد العمل (BR-xxx) | 04-BUSINESS-RULES |
| حالات الطلب والعرض والمقترح والفني | 21-STATUS-AND-STATE-MODEL |
| القرارات (DEC-xxx) | 34-DECISION-LOG |
| الإعدادات والمهلات (CFG-xxx) | 04-BUSINESS-RULES §الإعدادات |
| وضعا التشغيل ومفاتيح المرحلة | 39-OPERATING-MODES |
| ربط الوثائق بالكود | 40-CODEBASE-GUIDE |
| الهوية البصرية | 38-DESIGN-SYSTEM |

## المعرّفات المستخدمة
- `BR-xxx` قاعدة عمل — `DEC-xxx` قرار مالك — `OD-xx` قرار مفتوح — `ASM-xx` افتراض
- `CFG-xxx` إعداد قابل للتغيير — `NTF-xx` إشعار — `EVT-xxx` حدث في سجل الطلب
- `SCR-Cxx` شاشة عميل — `SCR-Pxx` شاشة فني — `SCR-Wxx` صفحة ويب — `SCR-Axx` شاشة إدارة
- `AC-xxx-nn` معيار قبول — `EC-xx` حالة استثناء
