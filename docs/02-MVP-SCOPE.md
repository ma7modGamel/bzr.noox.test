# 02 — نطاق النسخة الأولى

التصنيف: **MUST** = لازم لتشغيل التجربة بأمان وبشكل كامل · **LATER** = بعد التجربة · **NO** = غير مطلوب.
**FLAG** = مبني بالكامل في النسخة الأولى لكنه **معطّل بمفتاح في الإعدادات** ويُفعَّل من الداشبورد لاحقًا بلا إصدار جديد (39-OPERATING-MODES).

## مفاتيح المرحلة الأولى (DEC-039، DEC-040)
| المفتاح | الحالة عند الإطلاق | الأثر |
|---|---|---|
| CFG-090 عروض السعر | **معطّل** | لا عروض ولا اختيار؛ مدير التشغيل يعيّن الطلب لموظف مؤهل (T-27) |
| CFG-091 رسوم المعاينة | **معطّل** | كل طلب يبدأ بمعاينة مجانية، والسعر يُعرض من الموقع بعد الكشف |

## الفني
| الميزة | التصنيف |
|---|---|
| التحول لوضع الفني + معالج التسجيل + حالة المراجعة | MUST |
| مفتاح "متاح الآن" | MUST |
| الطلبات المتاحة + تفاصيل الطلب + تقديم/سحب عرض | **FLAG** (CFG-090) |
| استقبال طلب معيَّن من الإدارة (NTF-28) | MUST |
| إدارة الطلب النشط (تحرك، وصول، بدء، مقترحات، إنهاء، استلام نقدي) + دليل سعر الموظفين عند عرض التنفيذ | MUST |
| إرسال الموقع أثناء "في الطريق" | MUST |
| تقييم العميل | MUST |
| كشف المستحقات (العمولات، التحويلات، السداد) | MUST — في وضع الموظفين يعرض "المطلوب توريده" (BR-065) |
| الملف: نبذة، خبرة، تخصصات، مناطق، معرض أعمال | MUST |
| إحصاءات أداء متقدمة | LATER |
| اشتراك شهري | NO |
