# 38 — نظام التصميم المستخرج من اللقطات

**المرجع البصري الملزم**: لقطات `assets/screens/`. هذه الوثيقة تستخرج منها القيم لتلتزم بها كل الشاشات الجديدة (27). لا إعادة تصميم.

**طريقة الاستخراج**: اللقطات 800×1600 بكسل؛ اعتُبر عرض الشاشة المنطقي 400dp (مقياس 2×). الألوان مقاسة من البكسلات مباشرة، ولأن اللقطات JPEG فالهامش ±4 في كل قناة. الأحجام **مقاسة** (م) أو **تقديرية** (ت). عند توفر ملف التصميم المصدر (Figma وغيره) تُستبدل القيم به.

## 2. الخطوط
- خط عربي هندسي بعدة أوزان (عريض للعناوين، متوسط للنص). الاسم غير مؤكد من اللقطات (OD-07)؛ الأقرب شكلًا خطوط من عائلة Cairo / Tajawal / IBM Plex Sans Arabic.
- الأرقام: أرقام عربية غربية (350، 4.9، 18) في كل اللقطات ← تُعتمد.

| الدور | الحجم (sp) | الوزن | مثال |
|---|---|---|---|
| عنوان الشاشة | 22 (ت) | Bold | "تأكيد اختيار الفني" |
| رقم بارز | 32 (ت) | Bold | "18 دقيقة" |
| سعر | 24–26 (ت) | Bold، `primary-700` | "350 جنيه" |
| عنوان قسم | 18 (ت) | Bold | "تفاصيل العرض"، "طريقة الدفع" |
| اسم/عنوان كارت | 18 (ت) | Bold | "محمد السيد" |
| نص أساسي/زر | 16–17 (ت) | Medium/Bold للأزرار | "اختيار العرض" |
| نص ثانوي | 14 (ت) | Regular، `slate-500` | "يصل خلال 25 دقيقة" |
| نص صغير/شارة | 12–13 (ت) | Medium | "الأعلى تقييمًا"، "منذ 3 أيام" |

## 4. الزوايا والحدود والظلال
| العنصر | نصف القطر | |
|---|---|---|

| الكروت والبلاطات والحقول | ~10–12 | م |
| الشرائح والشارات | 8–10 | ت |
| كارت "اطلب خدمة" | 16 | ت |

- الحدود: 1dp `border`؛ العنصر المختار: 1.5dp `primary-600` + خلفية `primary-50`.
- الظلال: شبه معدومة؛ الفصل بالحدود. لا ظلال ثقيلة.

## 5. المكونات
| المكون | الوصف | اللقطة |
|---|---|---|
| رأس الشاشة | سهم رجوع (يسار)، عنوان في الوسط، أيقونة اختيارية يمين (علم الإبلاغ) | كل الشاشات |
| مؤشر الخطوات | 3 دوائر مرقمة بخط واصل + "الخطوة X من 3" | C03–C05 |
| بلاطة اختيار | أيقونة فوق نص، الحالة المختارة بحد وخلفية تركوازية | C03 |
| شريحة اختيار | نص في الوسط، مختارة بحد وخلفية تركوازية | C03، C04 |
| كارت راديو | راديو + عنوان عريض + نص ثانوي | C04، C08 |
| حقل رقمي بوحدة | حقل + مربع "جنيه" + وسم "اختياري" | C04 |
| مربع اختيار داخل شريط | مربع تركوازي مملوء بعلامة ✓ | C04، C05 |
| كارت ملخص بقسم "تعديل" | صفوف أيقونة + نص مفصولة بخط، زر "تعديل" صغير بخلفية `primary-50` | C05 |
| كارت عرض | صورة + درع، اسم، ★ تقييم + عدد الخدمات، شارة، سعر، وقت وصول، زر رئيسي + زر محادثة محدد | C06 |
| صف إحصاءات | 3 أعمدة بأيقونة + رقم + وصف، فواصل رأسية | C07 |
| أشرطة التقييم | نص البعد + شريط تقدم + الرقم | C07 |
| كارت مراجعة | صورة، اسم مختصر، نجوم، "خدمة مؤكدة"، الوقت، النص، وسم المشكلة | C07 |
| شريط سفلي ثابت | السعر الحالي + زر رئيسي + زر محادثة | C07 |
| صندوق تنبيه | خلفية `warning-bg` + ⚠ + نص | C08 |
| شريط معلومات | خلفية `primary-50b` + درع + نص تركوازي | C05، C07، C09 |
| كارت وقت الوصول | رقم كبير تركوازي + عنوان + أيقونة سيارة في دائرة | C09 |
| خريطة | زوايا مستديرة، صورة الفني عند موقعه، دبوس منزل تركوازي، زر "موقعي" | C09 |
| شريط المراحل | دوائر + خط، المكتملة مملوءة ✓، النشطة بحلقة | C09 |
| زر نصي خطِر | "إلغاء الطلب" أحمر بلا خلفية | C06، C09 |
| الشريط السفلي | 4 عناصر أيقونة + نص؛ النشط تركوازي | C01 |
| القائمة الجانبية | صورة + اسم + تقييم + "موثّق"، عناصر بمربع أيقونة وسهم، زر "وضع الفني" تركوازي كبير أسفلها | C02 |

المكونات الجديدة (ورقة سفلية، عداد تنازلي، حالة فارغة، حقل خطأ) تُبنى من نفس الرموز: ورقة سفلية بزوايا علوية 16، مقبض، عنوان قسم، ثم زر رئيسي.

## 6. الأيقونات
- أيقونات الواجهة: خطية (Outline) بسمك ~2dp، بلون `navy-800` أو `primary-600`؛ الدبوس والدرع مملوءان بالتركوازي.
- أيقونات الفئات: أسلوبان مختلفان في اللقطات (مجسمة ملونة في C03، مسطحة ثنائية اللون في C01) ← OD-08.
- رموز التوثيق: درع ✓ تركوازي على الصورة، ونقطة تركوازية قبل "فني … موثّق".

## 7. RTL والتخطيط
- اتجاه RTL كامل: الرجوع يسار الرأس، الأسهم في الكروت تشير يسارًا، الأزرار الرئيسية بسهم `<` يسارًا.
- الأرقام والمبالغ: الرقم ثم العملة ("350 جنيه").
- الشبكات: 3 أعمدة للفئات، عمودان للأزرار المزدوجة.

## 8. النصوص — الصيغة المحايدة (DEC-035، OD-09)
القاعدة: المصدر أو الاسم بدل فعل الأمر المؤنث؛ صيغة المتكلم ("عندي"، "أوافق") تبقى لأنها محايدة.

| في اللقطة | المعتمد |
|---|---|
| اطلبي خدمة | طلب خدمة |
| وصّفي المشكلة واستقبلي عروض الفنيين | وصف المشكلة واستقبال عروض الفنيين |
| اطلبي خدمة جديدة | طلب خدمة جديدة |
| اختاري نوع الخدمة | نوع الخدمة |
| حددي المشكلة | المشكلة |
| وصّفي المشكلة / اكتبي تفاصيل المشكلة هنا... | وصف المشكلة / تفاصيل المشكلة... |
| استكملي تفاصيل الطلب | متابعة تفاصيل الطلب |
| اختاري أو أضيفي عنوان الخدمة | اختيار أو إضافة عنوان الخدمة |
| استقبلي عروض رسوم المعاينة | استقبال عروض رسوم المعاينة |
| ميزانيتك المتوقعة / اكتبي السعر المقترح | الميزانية المتوقعة / السعر المقترح |
| استقبل عروضًا بدون تحديد ميزانية | استقبال عروض بدون تحديد ميزانية |
| غير متأكدة | غير محدد |
| راجعي طلبك | مراجعة الطلب |
| انشري الطلب واستقبلي العروض | نشر الطلب واستقبال العروض |
| رتبي حسب | ترتيب حسب |
| اختاري العرض / اختاري محمد | اختيار العرض / اختيار محمد |
| …لازم توافقي عليها داخل التطبيق قبل التنفيذ | …تتطلب موافقتك داخل التطبيق قبل التنفيذ |
| اتصلي | اتصال |
| شاركي تفاصيل الزيارة مع شخص موثوق | مشاركة تفاصيل الزيارة مع شخص موثوق |
| عميلة موثّقة | حساب موثّق |
| استقبلي الطلبات وقدّمي عروضك | استقبال الطلبات وتقديم العروض |
| عندي الخامات / أوافق على… / طلبك هيظهر… / إيه اللي محتاج يتصلّح النهارده؟ | بدون تغيير |

### نصوص وضع الموظفين (المرحلة الأولى — 39)
النصوص المرتبطة بالعروض تُستبدل، لا تُترجم؛ والمقاسات لا تتغير.

| في وضع السوق | في وضع الموظفين |
|---|---|
| وصف المشكلة واستقبال عروض الفنيين | وصف المشكلة وهنبعتلك فني مناسب |
| نشر الطلب واستقبال العروض | نشر الطلب |
| طلبك هيظهر للفنيين الموثقين القريبين منك | هنعيّن لك فني مناسب ونبلغك فورًا |
| استقبال عروض رسوم المعاينة | المعاينة مجانية، والسعر يُعرض بعد الكشف |
| استقبال الطلبات وتقديم العروض *(الفني)* | استقبال الطلبات المعيَّنة |
| بانتظار العروض *(حالة)* | جارٍ تعيين فني (SCR-C36) |
| إنهاء بالمعاينة فقط *(الفني)* | إنهاء بلا تنفيذ — بدون أي مبلغ |

النصوص البديلة أقصر أو مساوية للأصل في الأغلب، فلا تتغير المقاسات. اللهجة: مصرية خفيفة كما في اللقطات ("هيظهر"، "النهارده").

## 9. حالات يجب تصميمها بنفس النظام
فارغ (لا طلبات، لا عروض، لا إشعارات، ولا موظف متاح للتعيين في SCR-A15)، تحميل (هياكل رمادية بنفس أشكال الكروت)، خطأ في حقل (حد `danger` + نص صغير)، غير متصل، عداد تنازلي (رقم `primary-700` + نص ثانوي)، معطّل (الأزرار بشفافية 40%).
