# 03 — الأطراف والأدوار

## الأطراف
| الطرف | المسؤوليات | الحدود |
|---|---|---|
| **العميل** | إنشاء الطلبات، اختيار العروض، الموافقة على المقترحات، الدفع، التأكيد، التقييم، فتح المشاكل | لا يرى رقم الفني قبل التأكيد، ولا يلغي بعد الوصول (DEC-016) |
| **الفني** | إدارة ملفه وتوفره، تقديم العروض، تنفيذ الطلب، تقديم المقترحات، تأكيد الاستلام النقدي، تقييم العميل | لا يرى عنوان العميل التفصيلي ولا رقمه قبل التأكيد، ولا عروض غيره، ولا يقدم على طلبه |
| **مدير التشغيل** | مراجعة الفنيين، متابعة الطلبات، التدخل، النزاعات، التقييمات، البلاغات، حظر العملاء | لا يصل للمال ولا الإعدادات |
| **المدير العام** | كل ما سبق + العمولات، السداد، التحويلات، الاسترداد، الإعدادات، مستخدمي الإدارة | — |
| **النظام** | المهلات، الإغلاق التلقائي، الإشعارات، حساب المبالغ | ينفذ فقط انتقالات معرفة في 21 |

## الحساب الواحد والوضعان (DEC-001)
- هوية واحدة = بريد إلكتروني واحد (DEC-025).
- كل مستخدم **عميل** افتراضيًا. يصبح **فنيًا** بعد إنشاء ملف فني وموافقة الإدارة.
- التطبيق يعرض وضعًا واحدًا في كل مرة؛ كل وضع يعرض طلباته فقط.
- لا يستطيع الفني تقديم عرض على طلب نشره هو كعميل (BR-022).
- الإدارة حسابات منفصلة تمامًا عن المستخدمين (جدول `admins`).

الصلاحيات التفصيلية: 23-PERMISSIONS-MATRIX.
