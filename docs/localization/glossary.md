# Bilingual terminology glossary

Use these terms in controlled interface copy, API display labels and notification templates. Stable identifiers such as `order_id`, `PROVIDER`, `EXECUTION` and event keys remain unchanged. User-authored text and legal originals are never rewritten to enforce terminology. English legal drafts follow the Arabic source and remain pending approval.

Catalogs preserve parameter names and validate parity. Native resource plurals cover Arabic zero/one/two/few/many/other and English one/other. Notification plural tests cover 0, 1, 2, 3, 11 and 100 offers. Direct resource/formatter checks protect the screenshot-specific budget wording. Copy review uses the glossary above; automated key/script checks cannot certify linguistic quality or legal equivalence.
