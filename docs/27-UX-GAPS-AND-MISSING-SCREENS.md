# 27 — فجوات الواجهة والشاشات الناقصة

لا إعادة تصميم للأسلوب البصري؛ الشاشات الناقصة لا تحتاج تصميمًا، بل تُبنى من الوثائق وفق 43-UI-BUILD-CONTRACT، وكل شاشة جديدة تستخدم مكونات 38-DESIGN-SYSTEM.

## أ. شاشات موجودة تحتاج تعديلًا
| الشاشة | التعديل | السبب |
|---|---|---|
| SCR-C01 الرئيسية | حذف بانر الطوارئ؛ نصوص محايدة وفق قاموس 38 §النصوص ("طلب خدمة"، "وصف المشكلة واستقبال عروض الفنيين"؛ "إيه اللي محتاج يتصلّح النهارده؟" تبقى)؛ كارت "طلباتك الحالية" يعرض كل الحالات (ليس "استقبال العروض" فقط) | DEC-012، DEC-035 |
| SCR-C02 القائمة | "المحفظة والدفع" ← "طرق الدفع" (معلومات فقط) أو حذفه؛ "عميلة موثّقة" ← "حساب موثّق"؛ إضافة "الرسائل" غير لازم (موجودة في الشريط السفلي) | DEC-011، DEC-035، BR-005 |
| الرئيسية البديلة (خلفية SCR-C02) | البحث و"مميزون" و"أحدث الخدمات" لا تُنفذ | DEC-034 |
| SCR-C03 خطوة 1 | نصوص محايدة وفق 38 ("نوع الخدمة"، "المشكلة"، "وصف المشكلة"، "متابعة تفاصيل الطلب")؛ معاينة الوسائط المضافة مع حذف؛ عداد أحرف؛ علامة "إلزامي" عند "مشكلة أخرى" | BR-013، BR-014 |
| SCR-C04 خطوة 2 *(وضع الموظفين)* | إخفاء "طريقة التسعير" و"الميزانية" كليًا، مع سطر ثابت: "المعاينة مجانية، والسعر يُعرض عليك بعد الكشف" | BR-008، DEC-040 |
| SCR-C04 خطوة 2 | "اليوم" و"موعد آخر" تفتح SCR-C16 وتعرض الفترة المختارة تحت الأزرار؛ "الآن" يُعطَّل خارج ساعات الخدمة مع توضيح؛ توحيد "استقبل عروضًا بدون تحديد ميزانية" | BR-017، DEC-035 |
| SCR-C05 المراجعة | نصوص محايدة؛ رابط "الشروط وسياسة الإلغاء" يفتح SCR-C34 | BR-018 |
| SCR-C06 العروض | عداد تنازلي لنهاية النافذة/الاختيار؛ إخفاء "يصل خلال" و"الأسرع وصولًا" في المجدول؛ في المعاينة: "رسوم المعاينة" + شارة "تُخصم من المصنعية"؛ حالة "لا توجد عروض" (SCR-C35) بأزرار إعادة النشر/التعديل؛ زر "تعديل الطلب" قبل أول عرض | DEC-003، DEC-004، DEC-005، DEC-031 |
| SCR-C07 ملف الفني | أيقونة العلم تفتح SCR-C28؛ "متاح الآن" يظهر فقط إن كان مفعّلًا؛ زر "اختاري محمد" ← "اختيار محمد" | BR-121، DEC-035 |
| SCR-C08 التأكيد | "دفع إلكتروني" ← "دفع إلكتروني (فوري) بعد انتهاء الخدمة"؛ في المعاينة: "رسوم المعاينة" + نص الخصم؛ في المجدول: "الموعد" بدل "وقت الوصول"؛ التنبيه الأصفر يبقى كما هو | DEC-038، DEC-004 |
| SCR-C09 التتبع | الشريط يُكمل: تم التأكيد ← في الطريق ← وصل ← جاري التنفيذ ← الدفع ← مكتمل؛ الخريطة تظهر في "في الطريق" فقط؛ "إلغاء الطلب" يختفي بعد الوصول ويظهر "عندي مشكلة"؛ في CONFIRMED قبل التحرك: "في انتظار تحرك الفني" بدون خريطة؛ "شاركي تفاصيل الزيارة" ← "مشاركة تفاصيل الزيارة"؛ "اتصلي" ← "اتصال" | BR-070، DEC-030، DEC-035 |

## أ-2. ما يتغير في وضع الموظفين (39)
| الشاشة | التغيير |
|---|---|
| SCR-C05 المراجعة | نص "طلبك هيظهر للفنيين الموثقين القريبين منك" ← "هنعيّن لك فني مناسب ونبلغك فورًا" |
| SCR-C06/C07/C08 | لا تظهر؛ بعد النشر ينتقل العميل مباشرة إلى SCR-C36 |
| SCR-C09 التتبع | شريط المراحل يبدأ بـ "بانتظار التعيين" بدل "استقبال العروض" |
| SCR-C30 عرض التنفيذ | لا يظهر سطر "الخصم من رسوم المعاينة"؛ يظهر "المعاينة مجانية" + المبلغ المطلوب فقط |
| SCR-P08 رئيسية الفني | تختفي "الطلبات المتاحة" وتنبيه المستحقات؛ يظهر "طلب معيَّن لك" |
| SCR-P14 وصل | "إنهاء بالمعاينة فقط" ← "إنهاء بلا تنفيذ (بدون أي مبلغ)"؛ نموذج عرض التنفيذ يعرض نطاق المصنعية من الخادم، ويطلب سببًا عند الخروج عنه (BR-046) |
| SCR-P18 المستحقات | "الرصيد/المتاح للتحويل" ← "المطلوب توريده اليوم" + "قيمة خامات تُرد لك" (BR-065) |

| الشاشة الجديدة | المعلومات الأساسية |
|---|---|
| **SCR-C36** جارٍ تعيين فني | رقم الطلب، الملخص، "جارٍ تعيين فني مناسب"، الموعد، زر تعديل الطلب، زر إلغاء، بلا عداد عروض |
| **SCR-A15** لوحة التوزيع | الطلبات بلا تعيين مرتبة بالأقرب للمهلة (CFG-092/093)، وللطلب المحدد: الفئة، المنطقة، الموعد، الوصف والوسائط، وقائمة المؤهلين مع الحِمل الحالي وتعارض المواعيد، زرا تعيين وإعادة تعيين بسبب |

## ج. الشاشات الناقصة — الفني
كل وضع الفني ناقص (25). يُنفَّذ حسب ترتيب الدفعات الملزم في 43 §11. كل شاشة تستخدم نفس مكونات العميل (كروت، شريط مراحل، أزرار رئيسية/ثانوية، أوراق سفلية).

| الشاشة | المعلومات الأساسية |
|---|---|
| P08 | مفتاح متاح الآن، كارت الطلب النشط، قائمة الطلبات (الفئة، المشكلة، المنطقة، الموعد، تنفيذ/معاينة، الميزانية، منذ كم دقيقة، تقييم العميل)، تنبيه المستحقات |
| P10 | السعر، وقت الوصول (NOW)، تُخصم؟ (معاينة)، يشمل، ملاحظة، "صافي لك"، تنبيه تعارض الموعد |
| P12–P16 | نفس شريط المراحل في SCR-C09 من منظور الفني + العنوان التفصيلي + زر الملاحة + الهاتف |
| P18 | الرصيد، المتاح للتحويل، المعلّق، العمولات، التحويلات، السداد، حد المنع |

## د. ملاحظات اتساق بصري (بدون تغيير الأسلوب)
1. أيقونات الفئات: مؤقتًا الأسلوب المسطح ثنائي اللون (43 §2).
2. زر الطوارئ الأصفر يُحذف؛ اللون الكهرماني يبقى للتنبيهات والشارات (38).
3. صورة العميل في SCR-C01/C02 وتقييمه في القائمة: التقييم يظهر للعميل نفسه (مقبول)، ويظهر للفنيين كمتوسط (BR-024).
