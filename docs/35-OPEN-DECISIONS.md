# 35 — القرارات المفتوحة

لا يوجد قرار مفتوح يمنع بدء التنفيذ. كل البنود أدناه قيم إعداد أو تعاقدات أو محتوى.

بعد DEC-039/DEC-040 انتقل بندان من "قبل الإطلاق" إلى "قبل تفعيل CFG-090"، لأن العمولة وحد الدين لا معنى لهما مع موظفين (BR-065).

| المعرّف | الموضوع | ما المطلوب | التوصية | يوقف؟ |
|---|---|---|---|---|
| OD-01 | نسبة العمولة | قيمة CFG-062 | تُحدد تجاريًا (إعداد) | **قبل تفعيل CFG-090** (في وضع الموظفين النسبة 100% — BR-065) |
| OD-02 | حد دين الفني | قيمة CFG-061 | مبلغ يعادل عمولة 5–10 طلبات متوسطة | **قبل تفعيل CFG-090** (BR-063 لا يُطبق في وضع الموظفين) |
| OD-03 | مزود البريد | اختيار الخدمة | أي مزود SMTP موثوق بنطاق موثّق (SPF/DKIM) | قبل الإطلاق |
| OD-04 | النصوص القانونية | الشروط، سياسة الإلغاء، الخصوصية | مراجعة محامٍ؛ الوثائق تحدد المحتوى التشغيلي | قبل الإطلاق |
| OD-05 | مناطق التجربة | قائمة الأحياء في القاهرة | البدء بمدينة نصر + 3–5 أحياء مجاورة | قبل الإطلاق |
| OD-06 | إنستاباي لدفع العملاء | هل يُضاف لاحقًا؟ | عبر مجمّع دفع يدعم شبكة IPN، بعد التجربة | لا |
| OD-07 | الخط العربي | اسم الخط المستخدم في التصميم | يؤكده المصمم من الملف المصدر (38) | قبل تنفيذ الواجهات |
| OD-08 | أيقونات الفئات | مجسمة (خطوة 1) أم مسطحة (الرئيسية)؟ | توحيدها بأحد الأسلوبين؛ المصمم يقرر | قبل تنفيذ الواجهات |
| OD-09 | تفسير "الصيغة المحايدة" (DEC-035) | أمثلة القرار ("اطلب خدمة") بصيغة أمر مذكر | اعتماد **المصدر/الاسم** ("طلب خدمة"، "اختيار العرض") لأنه المحايد فعلًا؛ القاموس في 38 | قبل تنفيذ الواجهات |
| OD-10 | حساب فوري التجاري | فتح الحساب، الرسوم، بيانات الربط | يبدأ مبكرًا لأنه يستغرق وقتًا | قبل الإطلاق |
| OD-11 | عدد الموظفين وتغطيتهم عند الإطلاق | كم موظفًا لكل فئة/منطقة، وساعات ورديّاتهم | يكفي لتغطية ساعات CFG-020 في مناطق OD-05، وإلا تُضيَّق المناطق لا الساعات | قبل الإطلاق |
| OD-12 | سياسة أجر الموظف | راتب ثابت أم ثابت + حافز لكل طلب | خارج النظام تمامًا؛ النظام يوفر عدد الطلبات والتقييمات كمدخل للحساب اليدوي | قبل الإطلاق |
