# 24 — سجل أحداث الطلب

سجل تشغيلي خفيف (`order_events`)، ليس منصة تدقيق. يُكتب في نفس معاملة الإجراء، ولا يُعدّل ولا يُحذف.

## الحقول
`order_id`، `event_code`، `actor_type` (CUSTOMER / PROVIDER / ADMIN / SYSTEM)، `actor_id`، `from_status`، `to_status`، `ref_type` + `ref_id` (عرض، مقترح، دفعة، نزاع…)، `meta` (JSON صغير: السبب، المبلغ، المسافة…)، `created_at`.

## العرض
- **الإدارة**: خط زمني كامل في صفحة الطلب، بالترتيب، مع اسم المنفذ.
- **العميل والفني**: ملخص مبسط في تفاصيل الطلب (الحالات الرئيسية والمقترحات والدفع) بدون الأحداث الداخلية.
