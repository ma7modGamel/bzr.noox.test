# 17 — الإشعارات

القنوات (DEC-023، DEC-026): **Push (FCM) + داخلي** لكل الأحداث، و**بريد** للأحداث غير العاجلة. لا SMS (DEC-025).

البريد (DEC-049): يُرسل من `no-reply@{APP_DOMAIN}` عبر **ZeptoMail** (API أو SMTP من env)، بقوالب عربية RTL بألوان `tokens.json` واسم بريمو (سمة `bremo` مولّدة من `tools/gen-design`). روابط NTF-27 تفتح صفحات W02 على نطاق المنتج. خطوات النطاق (SPF/DKIM/DMARC) والاختبار الحقيقي في 44.
كل إشعار يُحفظ داخليًا أولًا (جدول `notifications`) ثم يُرسل Push عبر طابور؛ فشل FCM لا يمنع ظهور الإشعار داخل التطبيق (EC-22). الإشعار يفتح الشاشة المرتبطة (deep link).

## اختلاف الإشعارات حسب وضع التشغيل (39)
| الإشعار | وضع السوق | وضع الموظفين |
|---|---|---|
| NTF-01 طلب جديد مناسب | يُرسل لكل مؤهل | **لا يُرسل** |
| NTF-04 عرض جديد · NTF-05 تم اختيار عرضك · NTF-06 لم يُختر عرضك · NTF-21 أُعيد تفعيل عرضك | تُرسل | **لا تُرسل** |
| NTF-02 / NTF-03 | "بلا عروض" / "انتهى بلا اختيار" | نفس الرمزين بنص "لم يتوفر فني في الوقت المناسب" |
| NTF-20 اعتذر الفني | "طلبك يستقبل عروضًا من جديد" | "جارٍ تعيين فني بديل" |
| NTF-24 تجاوزت حد المستحقات | تُرسل | **لا تُرسل** (BR-065) |
| NTF-28 / NTF-29 | لا تُرسلان | تُرسلان عند التعيين وإعادة التعيين |

## تنبيهات الإدارة
داخل اللوحة فقط (عدادات 16)، بلا Push أو بريد في النسخة الأولى.

## الإعدادات للمستخدم
المستخدم يستطيع إيقاف NTF-18 فقط. باقي الإشعارات تشغيلية ولا تُعطَّل.
