# تقرير الدفعة 2 — عقد API المشترك

> **الحالة:** الدفعة 2 مقبولة، ونُفذت قرارات الإغلاق الأربعة اللاحقة. لم تبدأ أي شاشة من الدفعة 3. بقرار DEC-045 أُغلقت الدفعة 1 باعتماد لقطات Android، بينما التحقق البصري لـ iOS انتقل إلى الدفعة 8.

## ما تم

- اكتمل `GET /config` بحقول `tokens_version`، بنية `slots` و`limits`، وإصدارات التطبيق الدنيا، مع الإبقاء على إعدادات التشغيل التي تحتاجها الرحلة الحالية.
- كل تمثيل طلب يعيد `available_actions` بأسماء snake_case الثابتة في 31، و`deadlines` الخمسة، و`display_status` حسب الطرف، و`stepper` ذي الحالات `done/active/pending/on_hold`. في `OPEN/CANCELLED/EXPIRED` القيمة `null`، وفي `DISPUTED` تُحفظ `disputed_from_status` وتظهر مرحلتها `on_hold`.
- الوسائط: التسجيل الصوتي AAC داخل `.m4a` فقط، mono و64kbps، حتى 120 ثانية و5MB. أضيف عقد التسجيل نفسه إلى Android وiOS، والتحقق الفعلي على الخادم بـ `ffprobe` (هامش القياس المقبول 60–68kbps لاختلاف متوسط AAC المقاس عن قيمة الضبط 64kbps). بقيت حدود الصور والفيديو وإزالة EXIF والتخزين الخاص والتنظيف كما هي.
- المحادثة: إنشاؤها حسب العرض أو التعيين، مشاركو الطلب فقط، حجب التواصل قبل الاختيار، صور بعد التأكيد، وتحويل المحادثات غير المختارة/المنتهية للقراءة فقط.
- التتبع: يحسب الخادم ETA عبر Google Routes API (`DRIVE` + `TRAFFIC_AWARE`) عند بدء التحرك ثم كل 120 ثانية أو عند تجاوز 300 متر. عند فشل الخدمة يستخدم المسافة المستقيمة بسرعة 20 كم/س ويعيد `eta_approximate=true`.
- المشاركة: أضيفت مواصفة `docs/screens/SCR-W01.md` أولًا ثم صفحة الويب الفعلية بنمط D مبسط، RTL/Cairo وCSS مولّد من التوكنات، تحديث كل 30 ثانية، HTTP 410 للرابط غير الصالح، و`noindex/no-store`. القالب يستقبل View Model محدودًا ولا يستقبل بيانات العميل أو العنوان أو الموقع أو الهاتف أو السعر.
- التقييم المتبادل: نافذة `CFG-070`، مرة واحدة، وتحديث المتوسطات مع استبعاد المخفي.
- تحدّث `docs/api/openapi.json` من المسارات الفعلية، وأصبح `OrderAction` يعلن أسماء إجراءات الواجهات بدل أسماء الانتقالات الداخلية.

## رموز ومكونات ونصوص جديدة

- الرمز الجديد: `size.mobileContentWidth = 400` لصفحة المشاركة.
- الأيقونات: لا أيقونة جديدة؛ SCR-W01 تعيد استخدام `shield.svg`.
- المكونات/الحالات: `StatusStepper.on_hold` في Android وiOS والويب، وSCR-W01 تجمع `ProviderHeader` وكارت الحالة و`EtaCard` وشريط المراحل وصفّي الطلب/المنطقة.
- النصوص المشتركة الجديدة: `gallery.state.on_hold` = «متوقف مؤقتًا»، `eta.approximate` = «تقريبي»، `status.reviewing` = «قيد المراجعة».
- نصوص SCR-W01 الجديدة: «حالة الزيارة»، «رقم الطلب»، «المنطقة»، «فني [الفئة] موثّق»، و«انتهت صلاحية هذا الرابط».

## متطلبات التشغيل

- تشغيل migrations الجديدة، ومنها أعمدة `disputed_from_status` وحقول ETA المخزنة على `orders`.
- خادم الـ API يحتاج PHP `fileinfo` و`gd`، وأداة `ffprobe` للتحقق من مدة الصوت والفيديو.
- يلزم ضبط `GOOGLE_MAPS_SERVER_KEY` على الخادم؛ `GOOGLE_ROUTES_URL` له القيمة الرسمية الافتراضية ولا يحتاج ضبطًا عادة.
- الـ scheduler والـ queue يجب أن يعملا لكي تنفذ `media:purge-expired` كل ساعة.
- حتى يتحقق شرط «الرمز غير ظاهر في أي log» خارج التطبيق، يجب تعطيل أو تنقيح access log في موازن الحمل/خادم الويب لمسار `/v/*`؛ كود التطبيق نفسه لا يسجل الرمز.

## جدول التطابق

| العقد | Android | iOS | fixture / الفحص |
|---|---|---|---|
| `available_actions` وربط مفاتيح النص | حالات fixture مشتركة | `BzrCore.ActionBinding` | `mobile-core.json` على المنصتين |
| `deadlines` و`display_status` و`stepper.on_hold` | الحالة متحققة في الاختبارات | فك JSON وموديلات مستقلة عن UI | `swift test` على Linux |
| تنسيق المبلغ والوقت والتاريخ والعداد | `BzrFormat.kt` | `BzrFormatter.swift` ويستخدمه DesignSystem | نفس قيم `mobile-core.json` |

## غير المتحقق آليًا في iOS الآن

- العرض الفعلي لحالة `on_hold` ومقاساتها وألوانها على Simulator؛ يرجع للدفعة 8.
- تكامل التسجيل الصوتي مع AVFoundation على جهاز/Simulator؛ مواصفة AAC/m4a موجودة، لكن Linux يتحقق من العقد فقط.

## الأسئلة المفتوحة وحاجز CI

- لا توجد أسئلة عمل مفتوحة في القرارات الأربعة؛ كلها مطبقة وموثقة.
- لا توجد أسئلة عمل مفتوحة، ولا توجد بوابة macOS قبل الدفعة 3.
- workflow `Final iOS validation` جاهز ويدوي فقط (`workflow_dispatch`) على `macos-15` مع Xcode 16.2 ومحاكي iPhone 16، ولا يُشغّل الآن.
- لا يحتاج أسرار مشروع للمعرض؛ يحتاج عند الدفعة 8 مستودع GitHub مربوطًا وActions مفعّلة. `GITHUB_TOKEN` المدمج يكفي لرفع artifact.
